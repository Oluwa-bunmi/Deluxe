# Jewelry Store eCommerce

Welcome to the Jewelry Store eCommerce project! This application is built using React and provides a seamless online shopping experience for customers looking to purchase affordable jewelry. Here’s a quick overview of the features and functionalities included in this project:

## Features
- Latest Arrivals: Display the latest jewelry arrivals on the homepage.
- Product Listings: Browse through a variety of jewelry items, including detailed product descriptions and high-quality images.
- Search and Filter: Easily search and filter products based on categories, price range, and other attributes.
- Product Details: View detailed information and images for each product.
- Cart Management: Add items to the cart, update quantities, and remove items with ease.
- Wishlist: Save your favorite items to your wishlist for future purchase.
- Responsive Design: Enjoy a seamless shopping experience on any device, whether it’s a desktop, tablet, or mobile.

## Technologies Used
- React: A JavaScript library for building user interfaces.
- Redux: State management for handling cart and wishlist functionalities.
- Axios: For making HTTP requests to fetch product data.
- Tailwind CSS: For styling the application with a modern and responsive design.
